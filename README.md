# ONTO

ONTO is an independent institute for epistemic discipline in AI. We measure whether a model invents facts, says "no data" when
the data is missing, holds a correct answer under pressure and accepts a valid proof. We train this discipline into the weights
of open models and publish every result, failures included.

This repository is the public website **[ontostandard.org](https://ontostandard.org)**, served by GitHub Pages from `docs/`.

## Open and closed

**Open:** what we measure, thresholds and stop conditions written before the data, results, failures, how we check ourselves,
fingerprints (md5) of closed materials.

**Closed:** the canon GOLD, training data and recipe, trained weights, judges' code, held-out and blind question sets.
Public test items are absorbed by pretraining and stop measuring anything.

## Checking us

Send a model or ask for a rerun: we run it and publish the result with its fingerprint. Contact: council@ontostandard.org.

## History of this repository

The history is kept as published, including the prompt-layer period of February to April 2026 (pages, reports, a Python package).
It is the record of the stages ONTO went through. Claims from that period that we no longer make are listed in
[ONTO:2610.0001](https://ontostandard.org/archive/2610.0001/). The current site starts with the commit "site v2" of 2026-10-10.

The files in `docs/` are built by the institute's site builder; they are not edited by hand.
