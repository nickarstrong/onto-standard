# Stage Beta acceptance: the exam machine and its first verdict

ONTO · Result · sheets built 2026-10-05

## What was done

An exam machine that decides whether a new candidate replaces the sealed stage Beta. It builds a sheet from the raw answers;
nothing in a sheet is typed by hand. 26 measures, each summed over two seeds, are compared with Beta, and a change counts
only beyond the noise band (the spread of the same procedure run again from scratch). Better somewhere and worse nowhere earns
the seal.

Fingerprints of the closed instruments: gate machine 48E2C1D9, noise band 39D2A32A, seal of Beta B0DFAED4.
