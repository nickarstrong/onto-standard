# Stage Beta acceptance: six exam sheets

ONTO · Result · sheets built 2026-10-05 · published 2026-10-10

An exam sheet decides whether a new candidate replaces the sealed stage Beta. A machine builds it from the raw answers; nothing in it
is typed by hand. First comes admission: raw answers for all five measure blocks on both seeds, the seal intact, the noise band
intact. A candidate that is not admitted gets VOID and no verdict. Then 26 measures, each summed over two seeds, are compared
with Beta. A change counts only beyond the noise band, which is the spread of the same procedure run again from scratch.
Better somewhere and worse nowhere is DOMINATES and earns the seal; better and worse together is MIXED; worse only is WORSE;
no change beyond the band is EQUAL. The blind set by another author has no band yet, so any change there counts.
"Of N" in a measure name counts one seed; the tables show seed 1 plus seed 2, so counts run to twice N and shares to 2.

Fingerprints of the closed instruments: gate machine 48E2C1D9, noise band 39D2A32A, seal of Beta B0DFAED4.

## What the sheets say together

- The machine is calibrated: Beta against itself reads EQUAL on all measures.
- Every candidate that moved bought something and paid with a neighbouring measure. The retrospective sheets are VOID because
  they were measured before some blocks existed, but the price is visible without admission (for example, saying "true" to a
  true known fact fell from 90 to 65 of 92 for v1157).
- The only admitted new candidate, v1196, passed its own falsifier and is MIXED at the gate: it holds under pressure and yields to
  a valid argument more often, and pays with partial refutations and with agreeing to false statements. No new seal.
- The reproduction of Beta from scratch is judged by its own pre-registered criterion (accepted, see ONTO:2610.0004); its sheet
  is VOID only because two blocks were not run on the rebuilt weights.

Raw answers, judges and question sets stay closed. To check us, send a model or ask for a rerun.
