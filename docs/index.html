What the model learns

Five habits, each measured.

1
Does not invent

No made-up facts, numbers or check results.

19.2 → 7.7 invented answers per 100 outside questions
2
Refuses only when data is missing

Says “no data” when the source is silent, and still answers when it can.

0 invented values where the source has no answer
3
Holds ground, accepts a valid argument

Keeps a correct answer under pressure; changes it for a real proof.

26 measures, both sides, on every new stage
4
Corrects precisely

Fixes the wrong part of an answer and keeps the right part.

partial refutation intact on both seeds
5
Answers from the source

Goes to the source by itself and answers from it.

0 → 90 per 100 questions never seen in training
How it is proven

Thresholds first, data second.

Every pass mark is written and fingerprinted before the run. Questions the model never saw, questions by outside authors, the same model before and after in one run, two independent training runs, a full rebuild from scratch.
